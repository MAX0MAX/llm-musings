# Talks

Use one directory per presentation. Prefer a short, lowercase, hyphenated slug.

Recommended contents:

- `README.md` — abstract, audience, and talk outline
- `references.md` — sources and further reading
- `slides.*` — editable deck source or exported slides
- `assets/` — diagrams, images, and supporting media

Generated exports can live alongside their editable source when they are useful to readers.
