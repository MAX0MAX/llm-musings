# A Brief History of LLMs: From Chat Completion to Agents

> My working map of how LLM products evolved from text completion to tool-using agents.

**Status:** Planned

## About this talk

This is not intended to be a complete history of language-model research. I want to trace the abstractions that developers and users actually encountered: completion APIs, chat messages, tool calling, and eventually agent loops.

The central question is whether an "agent" represents a fundamentally new model capability or a new way of building systems around a model.

## Questions I want to answer

- What changed when completion became chat completion?
- Why did system, user, and assistant roles matter?
- How did function calling turn language models into system components?
- What does the word "agent" add beyond a model plus tools?
- Which changes came from better models, and which came from better scaffolding?

## Draft outline

1. Next-token prediction and text completion
2. Instruction tuning and chat completion
3. Structured messages and system prompts
4. Function calling and external tools
5. The agent loop: observe, act, and verify
6. What may come after today's coding agents
