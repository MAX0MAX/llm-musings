# LLM Musings

Personal talks and working notes on large language models, coding agents, and the systems around them.

This repository is a place to explain what I am learning, test ideas in public, and keep the source material behind each presentation. The talks are intended to be accessible rather than exhaustive or authoritative.

## Repository layout

Each presentation lives in its own directory under [`talks/`](talks/). A talk may include its slides, speaker notes, references, examples, and supporting assets.

```text

    README.md
    references.md

```

The format may evolve as the collection grows.
